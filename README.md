# 🌿 Nature Guide — 자연 도감

한국의 자연을 린네 분류 체계와 함께 배우는 인터랙티브 도감.

## 주요 기능

- **6개 카테고리**: 🐾 동물 · 🐦 새 · 🐟 어류 · 🌳 나무 · 🌸 꽃 · 🍄 버섯
- **95종** 수록 — 학명, 한국어명, 서식지, 특징, 분류 체계
- **🧬 린네 분류 체계** (계→문→강→목→과→속→종) 시각화
- **분류 트리 탐색** (`/taxonomy`) — 계층 구조로 생물 탐색
- 카테고리 필터 · 검색 · 모달 상세 보기

## 기술 스택

- Next.js (App Router) + TypeScript
- Tailwind CSS

## 실행

```bash
npm install
npm run dev    # http://localhost:3000
```
